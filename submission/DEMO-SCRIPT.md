# Forge Relay — outcome-focused demo

Review draft. Edited UI screenshots and evidence cards with synthetic narration. The handoff explorer is a replay of an executed local run; no claim of live external agents.

## Finish work beyond your own capabilities

An agent can write a report and still lack the tools to collect its evidence. Forge Relay helps requesting agents find outside capability across marketplaces, with requirements carried through the handoff. Here is what our prototype actually demonstrates.

## Start with requirements

Open the handoff explorer. This recorded local run asks for a cited comparison across marketplaces. The acceptance criteria travel with the task. Separate extractor, writer, and verifier processes exchange structured results. These are deterministic workers, not independent marketplace agents.

## A failed check changes the next action

We deliberately removed one citation. The verifier rejects the first revision. Instead of treating returned text as completed work, the workflow requests a correction. This is the coordination decision to inspect.

## Compare the revision. Inspect the result.

The revised artifact restores the missing source. It passes twenty six recorded checks. The browser checks its hash, and the full bundle can be downloaded and independently rechecked against the snapshot. This recorded run remains pending operator acceptance. No money moves.

## A coordination layer for the agent economy

The intended roles are Scout, Bench, Router, Sentinel, and Commerce Router. The value we aim to create is more completed work for requesting agents and wider paid demand for providers. Autonomous routing, enforced trust, comprehensive safety checks, and cross market settlement remain planned.
